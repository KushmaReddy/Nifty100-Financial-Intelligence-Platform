# Nifty 100 Financial Intelligence Platform

## 📌 Project Overview
This project builds a Financial Intelligence Platform for Nifty 100 companies using Python, SQLite, and financial datasets. It performs ETL, financial ratio calculations, company analysis, and dashboard generation.

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- SQLite
- OpenPyXL
- Streamlit
- Git
- VS Code

---

## 📂 Project Structure

data/
src/
db/
config/
docs/
tests/

---

## 🚀 Project Goal

To develop a complete Financial Intelligence Platform capable of:

- Loading Excel datasets
- Validating financial data
- Storing data in SQLite
- Calculating Financial Ratios
- Performing Company Analysis
- Building Dashboards
- Generating Reports
